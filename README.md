# Flutter Layout & Profile Page Lab

Welcome to the Profile Page practice lab! In this exercise, you will learn how to build a user interface from scratch using layout widgets (`Column` and `Row`), apply styling, and update the UI dynamically using `setState`.

## 🚀 Getting Started

1. Clone this repository to your local machine.
2. Ensure you have an image named `profile.png` inside an `assets` folder at the root of your project, and that it is properly declared in your `pubspec.yaml` file.
3. Run `flutter pub get`.
4. Open the project in your IDE.

## 📝 Your Tasks

Search for the `TODO` comments in `lib/main.dart` and build the widget tree step-by-step.

*   **TODO 1:** Define the main vertical structure using a `Column` widget.
*   **TODO 2:** Build the top section of the profile (Avatar, Divider, and Name).
*   **TODO 3:** Use a `Row` widget to place an Icon next to the Email text.
*   **TODO 4:** Add spacing and the "Points" label.
*   **TODO 5:** Use another `Row` widget to display a Star Icon next to the dynamic `points` variable.
*   **TODO 6:** Implement `setState` inside the Floating Action Button to make the points increase when clicked.

## ✅ Expected Output
When finished, you should see a beautifully structured profile page. Clicking the `+` Floating Action Button at the bottom right should instantly update the points counter on the screen!
